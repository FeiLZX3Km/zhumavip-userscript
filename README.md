# 竹马法考 · 解析页增强脚本

给[竹马法考](https://www.zhumavip.com/)与[众合教育](https://www.zhongheschool.com/)的解析页做界面增强的用户脚本。纯前端运行：不请求外部接口、不上传任何数据、不加载远程代码、不改动站点业务数据。

| 项目 | 内容 |
| --- | --- |
| 版本 | 3.20.5 |
| 许可证 | MIT |
| 作者 | WorkBuddy & FeiLZX3Km |
| 适用管理器 | Tampermonkey / Violentmonkey / ScriptCat 等 |
| 申请权限 | 仅 `GM_registerMenuCommand` |

## 功能

1. 解析自动展开，不必每次手动点“查看全部”。
2. 左侧答题卡收起后缩成极窄条，把宽度还给题目。
3. 四个操作按钮与统计卡归位到左卡。
4. 分屏：题目在左、解析在右，中间分割线可拖拽且宽度会被记住。采用克隆镜像模式，原件留在原地由 React 继续驱动，面板显示副本，内容签名变化自动重克隆。
5. 打分卡头部并成一行，打分提示入口挪到最右。
6. 视频、音频解析页：真播放器随分屏入驻右栏，原位置回填一个克隆占位，分屏与播放可以同时使用。
7. 分屏开关状态记忆：在扩展菜单里切换后写入 `localStorage`，刷新或重开解析页沿用上次选择；首次安装默认分屏。
8. 报告页面包屑修复：返回该部门法的练习目录页，而不是统一跳回题库首页。
9. 分屏左栏长题干全文：解除题干与选项区的定高、行数与溢出限制，题干自然撑高、下方选项随之下移；展开按钮在原件隐藏态仍可触发。
10. 深浅色主题：默认跟随浏览器的 `prefers-color-scheme` 自动切换，系统一变页面即时换色；油猴菜单里可在“跟随浏览器 / 固定浅色 / 固定深色”三态间循环，选择会被记住。深色只接管中性底色与中性文字，按页面分档处理，不做整页反色。
11. 状态色保护：做题报告页答题卡的对错红橙标注、选项的已选 / 错选 / 未选标记一律保留，选项块与题号圆点不被刷底。
12. 刷题页适配：顶部“切换风格”“字体大小”按钮与底栏翻页按钮在深色下可读，左栏题号方块不再是蓝底红字；左下角绿色调试统计水印自动隐藏。
13. 悬停高亮：站点把白底写在 `:hover` 上，深色下接管为柔和深底，不再出现白底白字的白块；固定浅色时完全恢复站点原样。
14. 章节目录页：深蓝章节链接提成亮蓝，暗字与半透明浅字一并提亮，整页文字可读。

## 安装与导入教程

分两步：先装用户脚本管理器（俗称“油猴”），再把 `.user.js` 导入进去。以下以 Tampermonkey 为例；Violentmonkey、ScriptCat 同样可用，脚本只申请了 `GM_registerMenuCommand` 一个权限。

### 第一步：安装 Tampermonkey

| 浏览器 | 安装入口 |
| --- | --- |
| Chrome、Edge、Brave 等 Chromium 系 | [Chrome 网上应用店](https://chromewebstore.google.com/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo) 或 [Edge 加载项商店](https://microsoftedge.microsoft.com/addons/detail/tampermonkey/iikmkjmpaadaobahmlepeloendndfphd) |
| Firefox | [Firefox 附加组件](https://addons.mozilla.org/zh-CN/firefox/addon/tampermonkey/) |
| Safari | 按 [Tampermonkey 官网](https://www.tampermonkey.net/) 的 Safari 说明安装 |

浏览器会提示“添加扩展”“读取和更改网站数据”，这是用户脚本的正常工作方式，确认即可。装完建议把扩展图标固定到工具栏，菜单命令要从这里点。

若应用商店打不开：到 [Tampermonkey 官网](https://www.tampermonkey.net/) 下载扩展包，在 `chrome://extensions` 打开开发者模式，用“加载已解压的扩展程序”导入；或改用 Edge 加载项商店装同一个扩展。

### 第二步：导入脚本

三条路任选其一，推荐第一条。

1. **Greasy Fork 一键安装（推荐）**：打开[脚本页](https://greasyfork.org/zh-CN/scripts/605587)，点绿色的“安装此脚本”，扩展会弹出确认页，核对名称、版本与两个 `@match` 后点安装。脚本页绑定了本仓库的同步源，日后仓库升版本会自动更新。
2. **GitHub raw 直装**：打开[本仓库脚本的 raw 地址](https://raw.githubusercontent.com/FeiLZX3Km/zhumavip-userscript/main/zhumavip-expand.user.js)，扩展识别到 `.user.js` 会弹出安装页，确认即可。
3. **本地文件导入**：下载仓库根目录的 `zhumavip-expand.user.js`，然后二选一：
   - 把文件拖进浏览器窗口，扩展会捕获并弹出安装页；
   - 点扩展图标 → 管理面板 → 加号新建脚本 → 全选粘贴脚本全文 → 保存（`Ctrl+S`）。

   若浏览器把 `.user.js` 当纯文本打开而不是触发安装，用第二种方式。

### 验证与更新

- 打开任意竹马法考或众合教育解析页，标签标题开头变成 `v3.20.5 | ...`，即表示脚本已注入；这是脚本自己写入的版本标记。
- 用户脚本只在页面加载时注入，装好或更新后要刷新一次页面才生效。
- 更新：Greasy Fork 的同步源会定期拉取仓库，只有 `@version` 递增才会生成新版本；手动安装的可在管理面板点检查更新。

## 菜单命令

在浏览器扩展图标的脚本菜单里：

| 命令 | 作用 |
| --- | --- |
| 切换调试高亮 | 给脚本识别到的元素加临时高亮，便于排查选择器 |
| 切换磨砂效果 | 开/关界面的磨砂背景样式 |
| 切换分屏开/关（视频页兜底·记住状态） | 一键退回站点原生布局，再点一次恢复分屏；选择会被记住 |
| 切换主题（跟随浏览器/固定浅色/固定深色） | 三态循环，即时生效并记住；跟随态下系统主题一变，页面无需刷新即换色 |

## 使用提示

- 分屏宽度记在 `localStorage` 的 `abuSplitPct`，开关状态记在 `abuSplitOff`。`localStorage` 按域隔离，两个站点各记各的。
- 同时打开多个标签时，其中一个切换状态，另一个要刷新后才跟上。
- 关闭分屏会退回站点原生布局，这是排查视频页播放器异常时的兜底入口，不是卸载脚本。
- 主题模式记在 `localStorage` 的 `abuThemeMode`（`auto` / `light` / `dark`），两个站点各记各的；固定浅色时所有深色规则都不生效，页面回到官方原样。深色下站点的对错状态色、题号圆点、图片、公式图和视频一律不染色。

## 实现要点

- **HASH 表**：站点使用 CSS Modules，类名是构建时生成的哈希。文件顶部集中维护这张映射表，站点改版导致样式失效时更新此表即可；文案级兜底仍在。
- **克隆镜像分屏**：不搬走 DOM 原件，避免破坏 React 的状态与事件绑定；右栏面板显示副本，靠内容签名比对决定是否重克隆。
- **长题干**：解除题干、选项容器的定高与行数截断，并按站点自身的收起态只点原件上的展开按钮（副本没有 React 事件）。
- **视频页**：拆面板前先把真播放器换回原位占位处，避免连播放器实例一起删除。
- **权限最小化**：只有一个 `GM_registerMenuCommand`，无 `@require`、无远程脚本、无混淆或压缩，代码可直接审阅。
- **主题变量**：把脚本自绘界面的十余处硬编码颜色收成 CSS 变量，浅深两套值挂在 `:root` 与 `html[data-abu-theme="dark"]`；`matchMedia` 监听系统主题变化，`storage` 事件让多标签同步手动选择。

## 已知边界

- 站点改版更换类名哈希后，需更新文件顶部的 `HASH` 表。
- 样式修复是按现象做的覆盖式处理，未逐条锁定站点原始样式属性。
- 只调整界面呈现，不涉及题目内容、答案数据或任何站点权限。
